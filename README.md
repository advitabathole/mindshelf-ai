# MindShelf AI 📚

An AI-powered book discovery platform that uses natural language processing and generative AI to provide personalized book recommendations and insights.

## Overview

MindShelf AI helps users discover books based on their interests by leveraging AI-generated recommendations and an interactive Streamlit interface.

## Features

- AI-powered personalized book recommendations
- Natural language processing for book discovery
- Interactive Streamlit user interface
- AI-generated summaries and insights
- Search and explore book recommendations

## Tech Stack

- Python
- Streamlit
- NLP
- LLM API
- Pandas
- Git/GitHub
